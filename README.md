A collection of Chrome extensions I've built for myself

## Youtube-Anti-Translate

A lightweight Chrome extension that prevents YouTube from automatically translating video titles and audio into your default language.

Instead, videos are displayed **in their original language**, preserving the creator's intended title and preventing unwanted auto-dubbing.

### Installation

1. Open the **Extensions** page in Chrome.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the **youtube-anti-translate** folder.
5. Make sure the extension is enabled.


## Video-Catcher

A Chrome extension for downloading private Google Drive videos that are not normally available for download.

### Installation

1. Open the **Extensions** page in Chrome.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the **Video-Catcher** folder.
5. Make sure the extension is enabled.

### Usage

1. Open the private non-downloadable Google Drive video you want to download.
2. Switch the video to the highest available quality.
3. Two new URLs should appear in the browser. If they do not, play the video and seek forward a few seconds.
4. Click the three-dot menu next to each URL to download the video and audio files separately.
5. Play both files together using a media player such as VLC, or merge them into a single file with a video editor.
6. **IMPORTANT:DISABLE THE EXTENSION AFTER USE!**
